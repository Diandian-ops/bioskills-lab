## 关键经验（可复用）
- **gate_lint 有两种模式**：`*-正文.md` / 含 `-小红书-` → 正文严格模式；其余（真实试用深拆笔记）→ 笔记(真实试用/通用)模式。**笔记模式更严**，会把「陷阱」「天花板」等词判为 METAPHOR（ERROR）。本次 007 笔记初稿因此 3 处 ERROR，改「降级陷阱→静默降级」「依赖天花板→依赖上限」后通过。写深拆版笔记时避开隐喻词。
- **工具未装时的真实试用**：multiple-alignment 的 CLI（mafft/muscle/clustalo/t_coffee）本机均未预装，用 `brew install mafft` 装好即跑通。其余未装工具（MUSCLE5/ClustalOmega/T-Coffee/PAL2NAL）的成分拆解按纪律只做忠实转述、不编造结果。
