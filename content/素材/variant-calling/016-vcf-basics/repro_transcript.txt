## 7) 格式转换与索引（SKILL.md 命令组）
$ bcftools view -Ob -o variants.bcf variants.vcf.gz    # VCF.gz -> BCF
  -> 2591 bytes
$ bcftools view -Ov -o variants.roundtrip.vcf variants.bcf   # BCF -> VCF
  ->      127 lines
$ bgzip variants.roundtrip.vcf   # -> .vcf.gz (bgzip, NOT gzip)
  -> variants.roundtrip.vcf.gz 已生成
$ bcftools index variants.roundtrip.vcf.gz   # -> .csi
  -> .csi 索引已生成
$ bcftools index -t variants.roundtrip.vcf.gz   # -> .tbi
  -> .tbi 索引已生成

## 8) 验证 SKILL.md 论断：plain gzip 非 BGZF，不可随机访问

$ bcftools index variants.gzip.vcf.gz   # 预期失败
