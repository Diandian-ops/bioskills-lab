    a) bedtools sort genes/peaks（closest 前置排序，SKILL 要求）
    b) bedtools closest -a peaks.sorted -b genes.sorted -D b -io -t first
       → nearest_db_io_first.bed（72 行，12 列 = A5 + B6 + 距离）
    c) closest -d -t all（默认 t=all 口径）→ nearest_all_d.bed（74 行）
    d) closest -D ref -io -t first → nearest_ref_io_first.bed
    e) closest -k 3 -d → top3_k3_d.bed（192 行）
    f) bedtools window -a peaks.sorted -b genes.sorted -w 50000 -c
       → window_counts.bed（72 行）
    g) awk 基因→TSS（SKILL 原样 awk）→ tss.bed（59 行）
       bedtools slop -i tss.bed -g genome.txt -s -l 2000 -r 200 → promoters.bed
    h) 对照组：bedtools slop -i genes.bed -g genome.txt -b 2000
       → genebody_slop_b2000.bed（错误启动子示范）
    i) bedtools flank -i genes.bed -g genome.txt -s -b 1000 → gene_flanks.bed

[4] 真值对账（parse_results.py → _parse.log / results.json）
    closest -D b -io -t first：
      最近基因指认 72/72 正确（100%，含 12 条 chr3 哨兵行 none/-1 也判对）
      非零符号距离值 60/60 与真值相等；方向符号 60/60 正确
    -t all：74 行 = 72 峰 + 2 平局峰各多 1 行；逐峰平局数与真值一致
    -D ref vs -D b：60 个非零 call 中 30 个符号翻转 = 全部 minus 链基因
      （与真值预期 30 一致；-D b 0 个翻转）
    -k 3 -d（无 -io）：31 个与基因重叠的峰首行即重叠基因、距离 0；
      其余 29 峰首行 29/29 与真值一致（192 行 = 60 峰 x3 + 12 哨兵 x1）
    window -w 50000 -c：逐峰计数 72/72 与真值相等；总命中 148 = 预期 148；
      均值 2.06 基因/峰；最大 5；chr3 12 峰为 0
    启动子 slop -s -l 2000 -r 200：59/59 区间坐标与真值逐条相等；
      56 条 2,201 bp（= 1 bp TSS + 2000 + 200，半开 BED 下限宽不是 2200）；
      3 条被静默截断：201 bp（chr2 起点 TSS=0）、701 bp（chr1 起点 500）、
      1201 bp（chr2 终点 minus 链）
    基因体 slop -b 2000 对照：均值 28,583.5 bp（最大 62,544 bp），
      与真启动子均值 2,124.7 bp 差一个数量级 —— 「基因体 slop 不是启动子」实测
    flank -s -b 1000：117 区 = 118 - 1（g006 起点为 0，左 flank 零长被丢弃）；
      g001 左 flank 截断为 [0,500) 但非空仍输出（每输入 2:1 假设只在内部成立）

[5] 口径发现（对账过程中确认，非文档转录）
    - closest -d 对不重叠特征报告的距离 = 间隔 bp 数 + 1（BED 半开坐标下
      bedtools 按含端点口径计距），写真值时须按 gap+1 对齐，实测 60/60 吻合。
    - slop 的 -l/-r 直接作用于 interval 的 start/end（-s 才按链交换），
      对 1 bp TSS 加 -l 2000 -r 200 得 2,201 bp 而非 2,200 bp。
    - flank 只丢弃零长侧翼；截断后非空的侧翼照常输出。
