2. 主链路（_run.sh，完整输出见 _run.log）
================================================================
samtools faidx ref.fa
cut -f1,2 ref.fa.fai > chrom.sizes                  # chr1  2000000
samtools view -bS sampleA.sam | samtools sort -o sampleA.bam -
samtools index sampleA.bam                          # sampleB 同理

# 深度核实
samtools depth -a -r chr1 sampleA.bam   # mean = 1.0295x
samtools depth -a -r chr1 sampleB.bam   # mean = 0.2577x（比值 3.99）

# genomecov：-bg 折叠等值段且省略零覆盖；-bga 额外铺零
bedtools genomecov -ibam sampleA.bam -bg  > A.bedgraph       # 27,427 行
bedtools genomecov -ibam sampleA.bam -bga > A_bga.bedgraph   # 33,372 行
bedtools genomecov -ibam sampleB.bam -bg  > B.bedgraph       #  7,435 行
bedtools genomecov -ibam sampleB.bam -bga > B_bga.bedgraph   #  9,669 行
# -bga 前三列区间长度合计 = 2,000,000 bp（全基因组铺满，实测）
# -bg A 覆盖 >0 的仅 820,627 bp（41.0%）；A 最高覆盖 78x
# bigWigInfo A.bw：basesCovered 820,627 / mean 2.509179 / max 78 / zoomLevels 8

# 手动 RPM（SKILL.md 提到的粗粒度 -scale 路线）
NA=20591, NB=5155 -> scale 因子 A=48.564907, B=193.986421（比值 = 3.994）
bedtools genomecov -ibam sampleA.bam -bg -scale 48.564907 > A_scaled.bedgraph
bedtools genomecov -ibam sampleB.bam -bg -scale 193.986421 > B_scaled.bedgraph

# 文本 -> bigWig（严格契约：C locale 排序 + 匹配 chrom.sizes）
LC_COLLATE=C sort -k1,1 -k2,2n A.bedgraph > A.sorted.bedgraph
bedGraphToBigWig A.sorted.bedgraph chrom.sizes A.bw   # OK，233,698 字节
bedGraphToBigWig B.sorted.bedgraph chrom.sizes B.bw   # OK， 88,848 字节

# bigWig 回读保真（pyBigWig 全染色体逐区间比对）
#   27,427 行（区间坐标一一对应），max |delta| = 0（无损往返）
#   bw.stats(chr1,780000,820000,mean) = 15.693；该窗口 4,840 个区间
#   -> fig3_bw_window.txt

# 多样本值矩阵
bedtools unionbedg -i A.bedgraph B.bedgraph -header -names A B > matrix_union.txt
# 28,103 行（含 header；union 区划把 A 27,427 + B 7,435 并成 28,102 个互不重叠区间）

3. bedGraphToBigWig 错误契约四项实测（全部 exit 255，逐条报错）
================================================================
[7a] 未排序输入（tac 反转）：
  "A.unsorted.bdg is not sorted at line 2. Please use the -sort option
   to sort the input file."
  注：本版本文案是 "...not sorted..."，非 SKILL.md 所写
  "is not case-sensitive sorted"——同一契约、不同措辞（真实发现）。
[7b] chrom.sizes 偏短（chr1 记为 1,000,000，即"错配 assembly"代理）：
  "End coordinate 1000122 bigger than chr1 size of 1000000 line 14191
   of A.sorted.bedgraph"
[7c] 重叠区间（A、B 两条轨道拼接）：
  "Error - overlapping regions in bedGraph line 10 of AB_overlap.bdg"
  修复实测：bedtools merge -i AB_overlap.bdg -d 0 -c 4 -o max
  34,862 行 -> 5,944 行，转换成功（AB.bw 生成）
[7d] 染色体命名不匹配（bedGraph 用 '1'，chrom.sizes 用 'chr1'）：
  "1 is not found in chromosome sizes file"
  注：本版本显式报错退出，未复现 SKILL.md "整条染色体静默缺失"
  的行为——静默路径存在于其他版本/其他违规组合，此处为显式拒绝。
