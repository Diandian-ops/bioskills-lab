D. 去重严格顺序 collate→fixmate→sort→markdup   [RECONSTRUCTED-FROM-LOG]
================================================================================

$ bwa-mem2 mem -t 8 -R '@RG\tID:s1\tSM:s1\tPL:ILLUMINA\tLB:lib1' \
      reference.fa reads_1.fq reads_2.fq | \
  samtools collate -@4 -O -u - | \
  samtools fixmate -m -@4 -u - - | \
  samtools sort -@4 -u - | \
  samtools markdup -@4 - aligned.markdup.bam
$ samtools index aligned.markdup.bam
  (stderr → md.log)

契约校验 (bwa_results.json -> markdup):
  rc=0, has_MC_tag=True, dup_flagged=2
  （fixmate -m 写入 MC/MS 标签；markdup 标出 2 个重复）

注: md.log 主流程与 §B 一致 (Processed 6000 reads in 0.122 CPU / 0.026 real)，
    差别仅在 SAM 写出耗时 (0.76 sec)，符合 markdup 管道增加的中间步骤。

E. -Y（软截 supplementary，SV 安全）vs -M（降级 secondary） [RECONSTRUCTED-FROM-LOG]
================================================================================

$ bwa-mem2 mem -t 8 -Y -R '@RG\tID:s1\tSM:s1\tPL:ILLUMINA' \
      reference.fa reads_1.fq reads_2.fq | samtools sort -@4 -o aligned_Y.bam -
$ bwa-mem2 mem -t 8 -M -R '@RG\tID:s1\tSM:s1\tPL:ILLUMINA' \
      reference.fa reads_1.fq reads_2.fq | samtools sort -@4 -o aligned_M.bam -
  (stderr → y.log / m.log)

契约校验 (bwa_results.json -> Y_vs_M):
  Y_supplementary_0x800 = 0
  M_secondary_0x100     = 0
  note: 合成参考无 SV 断点，二者均为 0；语义差异仅在真实 SV 数据显现：
        -M 把分裂片段降为 secondary(0x100) 会被 SV caller 跳过，
        -Y 保留 supplementary(0x800) 全程序列。
