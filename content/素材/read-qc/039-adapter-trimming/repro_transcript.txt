1. 命令清单（全部封装在 _run.sh，日志 _run.log；另有参数探针 _probe.sh/_probe.log）
================================================================
# 激活环境
source /opt/miniconda3/etc/profile.d/conda.sh && conda activate bio-qc

# step 1 造梯度数据（固定种子 39，20000 对/档，100 bp，1% 替换错误）
python3 make_inputs.py

# step 2 三档梯度 × 三种口径（G = 5p / 20p / 40p）
# ① cutadapt（SKILL.md PE 口径：共用 13 bp 茎环 AGATCGGAAGAGC）
cutadapt -a AGATCGGAAGAGC -A AGATCGGAAGAGC -m 20:20 \
  -o ca_${G}_R1.fq.gz -p ca_${G}_R2.fq.gz \
  grad${G}_R1.fq.gz grad${G}_R2.fq.gz > cutadapt_report_${G}.txt 2>&1

# ② Trimmomatic · A：SKILL.md 字面参数串
ADAPTERS_FA=$CONDA_PREFIX/share/trimmomatic-0.41-0/adapters/TruSeq3-PE-2.fa
trimmomatic PE -phred33 -threads 4 \
  grad${G}_R1.fq.gz grad${G}_R2.fq.gz \
  tm_${G}_R1_p.fq.gz tm_${G}_R1_u.fq.gz tm_${G}_R2_p.fq.gz tm_${G}_R2_u.fq.gz \
  ILLUMINACLIP:${ADAPTERS_FA}:2:30:10:2:keepBothReads MINLEN:36

# ③ Trimmomatic · B：仅把布尔位改为 true
trimmomatic PE -phred33 -threads 4 \
  grad${G}_R1.fq.gz grad${G}_R2.fq.gz \
  tmk_${G}_R1_p.fq.gz tmk_${G}_R1_u.fq.gz tmk_${G}_R2_p.fq.gz tmk_${G}_R2_u.fq.gz \
  ILLUMINACLIP:${ADAPTERS_FA}:2:30:10:2:true MINLEN:36

# step 3 以 truth.tsv.gz 逐读段真值统一口径评估
python3 analyze_results.py        # 产出 results.json / results.tsv / bins.tsv
python3 make_figs.py              # 产出 fig1/fig2/fig3 PNG + 自检
                                  # 末行打印 FIGURE QUALITY: TOTAL FAILS = 0

# 参数探针（_probe.sh，验证 ILLUMINACLIP 参数个数语法，见第 4 节）
wsl.exe -d Ubuntu -u root -- bash /mnt/d/1.WorkDir/RedBook/content/素材/read-qc/039-adapter-trimming/_run.sh

4. 参数探针摘录（_probe.log：ILLUMINACLIP 参数个数语法）
================================================================
probe A（4 参数 …:2:30:10:true） -> java.lang.NumberFormatException: For input string: "true"
probe B（5 参数 …:2:30:10:false）-> java.lang.NumberFormatException: For input string: "false"
probe D（6 参数 …:2:30:10:2:true）-> 正常运行，Both Surviving: 20000 (100.00%)
结论：Trimmomatic 0.41 的 ILLUMINACLIP 必须用 6 参数形态
  <fa>:<seedMismatches>:<palindromeClip>:<simpleClip>:<minAdapterLen>:<keepBothReads>
第 5 位 minAdapterLen 按 Integer 解析；第 6 位 keepBothReads 按
Boolean.parseBoolean 解析——SKILL.md 字面串里的单词 "keepBothReads"
被解析为 false，等价于显式写 false。

口径说明：
- trimmomatic_skill 的 dropped = 真值 read-through 对数（keepBothReads=false 丢 R2）；
  其 bases_removed 含整条被丢 R2 的 100 bp（1025/4029/8095 条 × 100 bp）。
- cutadapt false_clip = 干净读段上因默认 -O 3（最小 3 bp 重叠）被误剪的读段数，
  占干净读段 2.17% / 2.02% / 1.92%。
- 5-9 bp 残留召回 93.40% 的根因：默认 -e 0.1 按匹配区长度计错配数，
  5-9 bp 匹配允许 0 个错误，带 1% 测序错误的残留被漏检。
