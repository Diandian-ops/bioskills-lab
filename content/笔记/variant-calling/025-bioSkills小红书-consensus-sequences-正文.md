# 生成 consensus 前，先看基因型有没有定相

（编号 025 · 数据源：1000G Phase3 chr22，样本 HG00096，取 1 个长度为 200 kb 的窗口）

**要点一｜`-H 1` 在未定相数据上得到的更像嵌合体**
`bcftools consensus -H 1/-H 2` 只在基因型**已定相**（`0|1`，竖线）时才有意义。未定相（`0/1`，斜杠）时，「哪个等位属于单倍型 1」是每位点任意指派的，跨多个杂合位点取 `-H 1` 得到的是一条 switch-error 镶嵌体——不对应任何真实染色体，但看起来干净。取单倍型前先查：

`bcftools query -f '[%GT]\n' in.vcf.gz | grep -c '|'`

**要点二｜一条自洽性恒等式，能自检定相对不对**
实测（SNP-only，各投影等长 200001 个碱基）：

| 投影 | 与参考差异位点数 |
|---|---|
| `-H A`（全部 ALT） | 522 个位点 |
| `-H R`（杂合取 REF） | 107 个位点 |
| `-H 1` 单倍型 1 | 440 个位点 |
| `-H 2` 单倍型 2 | 189 个位点 |

含 ALT 位点共 522 个，其中纯合 ALT 有 107 个，所以杂合位点 = 522 − 107 = **415**。而实测单倍型 1 与单倍型 2 的差异**正好 415**。这条恒等式成立，说明两条序列是各自真实的染色体；未定相数据上它就不成立了——**不用外部真值集也能自检**。

顺带看清各有损方式：`-H A` 的 522 个比任一真实单倍型都多（它把两条染色体的 ALT 并进一条不存在的序列）；`-H R` 只有 107（丢光杂合 ALT）；IUPAC 投影产生 408 个简并字符，保留了杂合却丢了相位，而且**很多建树程序会把 IUPAC 当 N 丢掉**。

**要点三｜符号 SV 用不了，无覆盖位点会伪装成参考**
VCF 里有 `<INS:ME:ALU>` 这类符号等位时，consensus 直接失败：`Symbolic alleles other than <DEL>, <*> or <NON_REF> are currently not supported`。文档给的修正是加 `-e 'ALT~"<.*>"'` 排除。

另一件更要紧的：VCF 沉默的位置一律照抄参考碱基，**包括覆盖度为零的位置**——「没测到」和「确证是参考」在输出里长得一样。必须按深度做 mask，而且 `samtools depth` **一定要加 `-a`**，否则零覆盖位置根本不进 BED，永远不会被 mask 掉。

**结论**：consensus 是二倍体的有损投影。用前先定相、先 norm、排符号等位、按深度 mask；相位敏感的分析就别用单条 consensus，保留 VCF 或两条定相单倍型。
