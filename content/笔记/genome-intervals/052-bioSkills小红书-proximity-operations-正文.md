# bedtools 最近基因，能信几成

（编号 052 · 真跑日期 2026-09-03：WSL Ubuntu + bedtools v2.31.1；模拟 3 条染色体、59 个基因、72 个峰，造数据时就算好全部真值用于逐条对账）

**封面卡｜closest 答的是几何题，不是调控题**
`bedtools closest` 输出的是「坐标上最近的注释基因」，而做峰注释的人想要的是「这个峰调控哪个基因」。skill 引用的金标准（Fulco 2019）里，把远距离元件指给最近表达基因：精确率约 47%，召回率约 37%——最近基因多数时候不是调控靶标。

**发现一｜指派可以全对，结论照样要打折**
72 个峰的最近基因指派与真值 72/72 一致（100%）；60 个非零符号距离逐条相等（60/60）；12 个落在无基因染色体的峰正确输出 none/-1 哨兵。几何计算零失误——但几何对不等于生物学对，这正是 skill 划的两个场景：增强子找靶标（最近基因多数时候是错的）vs GWAS 位点找基因（最近蛋白编码基因约 50-65% 正确，是难以击败的公平先验）。

**发现二｜默认 -t all 会在双向启动子处加行**
2 个设计在头对头基因对正中央的峰，让输出从 72 行膨胀到 74 行——平局行恰好落在双向启动子位置。拿这种输出直接做逐基因计数或富集，显著性会被系统性抬高。修法：-t first（须注明口径）或按 distinct 峰聚合，富集场景 skill 推荐 GREAT 的调控域模型。

**发现三｜-D ref 把 minus 链基因的上游下游全部折反**
同一份数据，-D ref 有 30 个指派的符号与链特异真值相反（-D b 为 0 个），这 30 个恰好就是指到 minus 链基因的那些峰——要看峰在基因上游还是下游必须用 -D b。顺带三个边界口径实测：不重叠特征的 -d 距离 = 间隔 bp 数 + 1（含端点口径）；对 1 bp TSS 做 slop -l 2000 -r 200 得 2201 bp 而非 2200 bp；slop/flank 在染色体端静默截断——59 个启动子有 3 个被截成 201/701/1201 bp 且无警告，118 条侧翼被 flank 丢弃 1 条。

**结论**：closest/window/slop/flank 的坐标计算可以与真值逐条吻合（本次全部对上），但「最近基因」作为调控结论只值约 47% 精确率——几何全对之后，把远距离元件诚实路由到 ABC/PCHi-C/eQTL 才是这套工具的正确收尾。
